TOTO PREDICTOR LITE
===================

App ini berasingan daripada Rumah A Predictor.

Kandungan:
- Keputusan terbaru (read-only)
- Input Top 3 dan butang Generate
- Bridge V1
- Bridge Pair Shortlist

Keselamatan:
- Tiada History Manager
- Tiada upload fail
- Tiada GitHub token
- Tiada fungsi save atau auto-save
- Bacaan GitHub adalah read-only

Deploy sebagai projek Streamlit yang berasingan menggunakan app.py.
